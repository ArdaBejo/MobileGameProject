# CA2 gameplay capture

Record a 3–5 minute portrait gameplay video on the signed Android candidate, build `620b79a5`. Aim for about 3:30. Use the phone's screen recorder and start recording on the Android home screen. The CA2 handout requests a gameplay recording and separate device proof. Capture the device model separately in Settings → About phone.

| Approximate time | Capture |
| --- | --- |
| 0:00–0:20 | Tap the No Stars Remain icon. Keep boot, loading and the main menu in the clip. Tap Start Game. |
| 0:20–2:45 | Play one full arena run through the Result screen. Show drag movement, automatic fire, waves and a coin-funded upgrade if affordable. Briefly open Pause, then Resume so the timer visibly continues. |
| 2:45–3:30 | Show the Result screen, return to Android, close the app from Recents and relaunch from its icon. Keep the relaunched Menu in frame. |

Enable Do Not Disturb before recording. Review the exported MP4 for legibility and the complete sequence. Place it under `Video/` in the CA2 submission ZIP. If recording on the emulator, identify it in the video filename or caption and confirm whether that capture is accepted for CA2.
