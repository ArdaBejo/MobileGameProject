# Closed test instructions

1. Scan the APK QR and download the file from Drive. Compare the version and SHA-256 with the build record if you can.
2. Open the downloaded APK on an Android ARM64 device. If Android blocks installation, record the exact message before asking for help. If you have an older app signed by a different key, uninstalling it removes its saved data; only do this if you are willing to lose that data.
3. Open **About** from the title screen and select **Copy build ID**. The build ID tells us which APK you tested.
4. Play for five minutes. Note any freeze, crash or not responding message, and what you were doing when it occurred.
5. Open **About → Feedback** and submit the anonymous form. If installation failed, use the standalone responder link and enter 0 minutes.

Observe the first 30 seconds without explaining the controls. Log hesitations and actual outcomes in the device matrix. The first two responses should come from two separate real peer phones. Then widen the closed test to reach the Pack 3 sample.
